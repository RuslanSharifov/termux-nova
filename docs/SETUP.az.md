# Termux Nova — Azərbaycanca

## Android Termux — hamısını bir dəfə kopyala-yapışdır

```bash
pkg update -y && pkg install -y git && \
cd "$HOME" && \
git clone https://github.com/RuslanSharifov/termux-nova.git && \
cd termux-nova && \
bash install.sh && \
source "$HOME/.bashrc" && \
clear
```
